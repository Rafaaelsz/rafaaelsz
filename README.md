* **Finder Vagas TI** — Aplicação voltada para busca e organização de vagas na área de tecnologia.

* **Portfolio Full Stack** — Portfólio profissional desenvolvido com foco em performance, design moderno, experiência do usuário e apresentação dos meus projetos.
